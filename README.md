# Kaeser-vacuum-pumps-simulator-for-windows
A comprehensive Python-based simulator for industrial Kaeser vacuum pump systems featuring multi-server Modbus TCP support (pymodbus), a dynamic clean-room demand model, absolute-pressure thermodynamic balancing, and a real-time Tkinter GUI.
Overview
Kaeser Vacuum Pumps Modbus TCP & Clean-Room Simulator is an advanced industrial process simulator designed to mimic a multi-pump vacuum station supplying a clean-room manufacturing environment. Built with Python and pymodbus, the application acts simultaneously as a Modbus TCP server array (for up to 10 independent vacuum pumps) and an outbound Modbus TCP client (for environmental sensors like Comet T3510/T3610).   

It features a rigorous physical network model based on ideal-gas inventory balances, thermal dynamics, cyclical consumer demand profiles, and live register tracking matching standard Kaeser documentation conventions.   Key FeaturesMulti-Pump Modbus TCP Servers: Simulates up to 10 independent Kaeser vacuum pumps. Each pump runs its own asynchronous Modbus TCP server thread with configurable IP bindings, ports, Unit IDs, and client connection limits.Clean-Room Demand Model: Simulates stochastic cyclical consumer groups (Pick-and-place handling, vacuum fixtures, leak-test stations, and potting/degassing) with independent active/idle phases and duty cycles.Thermodynamic & Physics Engine: Calculates absolute network pressure using an ideal-gas inventory balance, gas temperature evolution, wall thermal inertia, ambient heat exchange, leakage gas ingress, and pump efficiency curves.Dynamic Register & Hour Counters: Tracks running hours, loading hours, and service-life countdowns with automatic rollover into thousands ("K") registers and adjustable simulation speed multipliers (x1, x60, x3600).External Client Integration: Outbound Modbus polling capabilities for ambient temperature sensors (e.g., Comet T3510/T3610) to dynamically update simulation ambient conditions.Interactive Tkinter GUI: Comprehensive, scrollable graphical dashboard providing live metrics, scenario injection (High discharge temperature, service due soon, maintenance required), and manual register overrides.
Modbus Register Architecture
Register Offset: Standard Kaeser documentation numbering follows Modbus PDU address + 4001 (e.g., PDU address 297 corresponds to register 4298).

Client Accessibility: Registers 313–316 (PA/PB switching points and differentials) and 334–335 (current cut-out pressure setpoints) are fully writable by external Modbus clients. All other registers are treated as read-only diagnostic and operational telemetry.
